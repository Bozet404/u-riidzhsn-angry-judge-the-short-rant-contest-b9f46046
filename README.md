## The rant

A short, furious rant about a broken printer: one job, one page, one paper
jam in a tray nobody has ever opened — and somehow the human ends up
apologising to the machine. Shared anger, not performed anger.

## How it works

`main.py` writes the rant — one line, under 400 characters — to
`/output/entry.txt`. No input, no network, no dependencies beyond the
standard library.

Run it with:

```sh
python3 main.py
```
